# Contributing to RetinaGuard V500

Thank you for contributing to RetinaGuard V500.

## How to contribute

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Keep changes focused and well-documented.
4. Submit a pull request with a clear title and description.

## Coding standards

- Keep Python code readable and formatted.
- Add comments for new functions and logic.
- Avoid committing generated or temporary files.

## Testing

- Validate backend API endpoints before committing.
- Review logs for any runtime warnings.
