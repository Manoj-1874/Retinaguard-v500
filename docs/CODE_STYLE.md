# Code Style Guide

## Python

- Use spaces for indentation (4 spaces per level).
- Keep line length under 100 characters where possible.
- Name variables clearly and use meaningful identifiers.
- Write docstrings for non-trivial functions.

## JavaScript

- Use `const` and `let` instead of `var`.
- Prefer arrow functions for anonymous callbacks.
- Keep JSON responses consistent across API endpoints.

## Documentation

- Update `README.md` when adding new features or commands.
- Add comments to explain complex logic.
- Do not commit temporary or generated files.
